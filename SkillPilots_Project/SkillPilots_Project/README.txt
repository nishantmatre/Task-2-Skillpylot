SkillPilots Dashboard UI Demo

HOW TO RUN
1. Extract SkillPilots_Project.zip.
2. Open the extracted folder.
3. Double-click index.html, or open it in Chrome.
4. Click "Steps" or "Submit Project" to open the implementation steps popup.

FILES
- index.html: page structure
- style.css: dashboard styling and responsive layout
- script.js: learning day cards and popup interactions

NOTE
This is a front-end recreation based on the screenshot provided. It is not the original SkillPilots website source code and does not connect to the real SkillPilots account or backend.
